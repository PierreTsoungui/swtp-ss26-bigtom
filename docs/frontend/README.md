# Frontend Documentation

This folder contains documentation related to the frontend application, its structure, and its interaction with the rest of the system.

## Contents of This Section

- [components-reference.md](components-reference.md) – Reference for the main frontend components and their responsibilities.
- [hooks-reference.md](hooks-reference.md) – Overview of the custom hooks used by the frontend.
- [theming.md](theming.md) – Documentation of the frontend theming and styling approach.
- [diagrams/](diagrams/) – Visual diagrams and related frontend architecture illustrations.

## Purpose

The documents in this folder help developers understand the frontend implementation and how the user interface is organized and connected to the backend services.
