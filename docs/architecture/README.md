# Architecture Documentation

This overview serves as an entry point to the project's architecture documentation. It summarizes the most important technical and process-related documents and helps you quickly understand the system structure.

## Contents of This Section

- [System_Overview.md](System_Overview.md) – Overview of the overall system and its main components.
- [backend-architecture.md](backend-architecture.md) – Architecture of the FastAPI backend.
- [frontend-architecture.md](frontend-architecture.md) – Structure of the React/TypeScript frontend application.
- [job-lifecycle.md](job-lifecycle.md) – Lifecycle of analysis jobs and their states.
- [pipeline-progress.md](pipeline-progress.md) – Representation of pipeline progress and workflow steps.
- [r-executor.md](r-executor.md) – Execution of R-based analysis steps.
- [r_backend-architecture.md](r_backend-architecture.md) – Structure and responsibilities of the R backend.

## Purpose

The documents in this folder describe how the frontend, backend, R worker, and job management work together. They are especially useful for developers, operators, and maintainers.
